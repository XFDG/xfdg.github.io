LLMQRT：量化推理 Runtime

基于 PyTorch Extension，为 H200 双卡交付 32B 量化推理与 Tensor Parallel。

项目索引

问题与职责

面向 H200 双卡上的 32B 量化推理，需要打通量化后端、Attention、KV Cache 与多卡通信，并排除尾组越界。

负责 W4A16 / W8A8 / FP8 后端适配，接入 FlashAttention-2/4、GQA、softcap 与 SDPA。使用 Compute Sanitizer 定位 gemv_kernel_g128 尾组越界并补充保护；实现 Qwen2 packed-AWQ TP=2 列 / 行切分及 NCCL all-reduce。
