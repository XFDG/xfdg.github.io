LLMQRT: quantized inference runtime

A PyTorch Extension runtime for two-H200, 32B quantized inference and tensor parallelism.

Project index

Problem & contribution

Deploying a 32B quantized model on two H200 GPUs required integration across quantization backends, attention, KV cache and collectives, plus tail-group memory-safety fixes.

Adapted W4A16 / W8A8 / FP8 backends and integrated FlashAttention-2/4, GQA, softcap and SDPA. Used Compute Sanitizer to isolate gemv_kernel_g128 tail-group out-of-bounds accesses; added guards, packed-AWQ TP=2 column/row sharding and NCCL all-reduce.
