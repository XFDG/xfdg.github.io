写作台

文章留在自己的站点，讨论发生在更远的地方。

用 GitHub 登录写作后台 ↗查看博客

01 / 写作

首次打开 Pages CMS，用 GitHub 登录，仅授权 XFDG/xfdg.github.io。进入「博客文章」，填写标题、固定地址、日期和正文；编辑器支持 Markdown 源码与图片上传。

02 / 发布

打开「发布到网站」再保存。GitHub 自动构建文章、目录与 RSS；完成后访问 /blog/固定地址/。首次发布后不要随意修改固定地址。

03 / 分发

在文章页复制链接或 Markdown 引用到洛谷；同步按钮调用浏览器中的 Wechatsync，把正文和图片发送到 CSDN / 知乎草稿箱，再到平台确认发布。

开始之前

当前仓库是公开的：后台保存的未发布文章仍能在 GitHub 源文件与历史记录中看到。未准备公开的内容，请先写在本地；发布开关仅控制网站是否展示。

Wechatsync 是第三方浏览器扩展，安装前请检查它的账号与网站访问权限。本站不要求输入平台密码、Cookie 或 GitHub Token。公式和复杂排版在跨平台后仍建议检查；平台更新也可能导致同步失败。
